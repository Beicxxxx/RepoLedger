# Existing-ledger example

Copy this folder outside the RepoLedger checkout, run git init and git add .
there, then run repo-ledger lookup TASK-1 --json and repo-ledger check --json
using the locally installed CLI. Do not run init over this existing ledger.
The sample DONE status is illustrative, not CLI-verified proof of completion.
Use ../demo.py for an automatically executed fresh-ledger lifecycle.
